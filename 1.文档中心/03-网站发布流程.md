# 网站发布流程

将构建产物压缩为一个文件，上传服务器后解压到 `/www/wwwroot/WebSite/lordsite`。服务器只需提供静态文件访问，不需要安装 Node.js。

## 1. 本地构建并压缩

在项目根目录执行（首次使用或依赖变更时先运行 `npm ci`）：

```sh
npm run build && COPYFILE_DISABLE=1 tar --exclude='.DS_Store' -czf /tmp/lordsite.tar.gz -C dist .
```

生成的发布包为 `/tmp/lordsite.tar.gz`，包内直接是网站文件，不包含外层 `dist` 目录。

## 2. 上传服务器

将下方 `用户名@服务器地址` 替换为实际 SSH 登录信息，在本地执行：

```sh
scp /tmp/lordsite.tar.gz 用户名@服务器地址:/tmp/lordsite.tar.gz
ssh 用户名@服务器地址
```

也可以使用服务器面板，将压缩包上传到服务器的 `/tmp/lordsite.tar.gz`。

## 3. 在服务器解压发布

登录服务器后执行，登录用户需有网站目录写入权限：

```sh
mkdir -p /www/wwwroot/WebSite/lordsite
tar -xzf /tmp/lordsite.tar.gz -C /www/wwwroot/WebSite/lordsite
```

解压会覆盖同名文件，不会删除旧文件。确认网站配置的根目录是 `/www/wwwroot/WebSite/lordsite`，然后打开网站，检查首页、微信二维码和全站搜索即可。

每次更新都重复以上步骤；只需上传压缩包，不用上传源码或 `node_modules`。
